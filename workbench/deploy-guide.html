🚀 宇宙边角办事处 · 极简部署教程

跟着做就行，每一步都写清了点哪个按钮 · 大约 20 分钟全部搞定

📑 本教程包含 3 个部分

1把工作台部署到 Vercel（获得永久公网网址） 2配置 jsonbin.io 双向数据同步（电脑↔手机自动同步） 3小米手机添加桌面图标（像 App 一样全屏使用）
📍 第一部分

把工作台部署到 Vercel

目标：得到一个 https://xxx.vercel.app 永久网址，电脑和手机都能打开，不会休眠，免费 forever。

注册 GitHub → 上传源码 → Vercel 导入 → 获得网址
1 注册 GitHub 账号

① 在电脑浏览器打开 https://github.com

② 点击右上角 Sign up 按钮

③ 输入你的邮箱 → 设置密码 → 设置用户名 → 完成验证码 → 点击 Create account

④ 去邮箱收验证码，输入后激活账号

⑤ 登录成功后，页面显示你的 GitHub 主页，注册完成

已经有 GitHub 账号？直接跳到第 2 步。
2 在 GitHub 创建一个新仓库

① 登录 GitHub 后，点击右上角头像旁边的 ＋ 号 → 选择 New repository

② 在 Repository name 输入框里填：cosmos-workbench

③ 下方找到 Add a README file 选项，打勾（这样仓库不会是空的）

④ 滑到最下面，点 Create repository 绿色按钮

⑤ 页面跳转到你的新仓库，显示一个 README.md 文件，创建成功

3 把 workbench 文件夹里所有文件上传到仓库

① 在仓库页面点击 Add file 按钮 → 选择 Upload files

② 打开电脑上的 workbench 文件夹（就是 index.html 所在的那个文件夹）

③ 全选文件夹里的所有文件和子文件夹（Ctrl+A 全选），然后拖拽到 GitHub 网页上的上传区域

④ 等待文件上传完成（左下角进度条走完）

⑤ 上传完成后，页面下方 Commit changes 区域，直接点 Commit changes 绿色按钮

注意：要上传的是 workbench 文件夹里面的内容，不是 workbench 文件夹本身。仓库根目录应该直接看到 index.html、css、js、icons 等。
文件较多？GitHub 一次最多拖 100 个文件。workbench 大约 27 个文件，可以一次拖完。如果有子文件夹（css、js、icons），GitHub 会自动保留目录结构。
4 注册 Vercel 账号

① 在电脑浏览器打开 https://vercel.com

② 点击右上角 Sign Up

③ 选择 Continue with GitHub（用 GitHub 账号登录，不用再注册一次）

④ 弹出授权页面，点 Authorize Vercel 同意授权

⑤ 可能让你填一个昵称，随便填 → 点 Continue

⑥ 进入 Vercel 控制台首页（Dashboard），注册完成

5 导入 GitHub 仓库，一键部署

① 在 Vercel 控制台首页，点击 Add New... 按钮 → 选择 Project

② 页面显示你的 GitHub 仓库列表，找到 cosmos-workbench → 点击右侧 Import 按钮

③ 进入配置页面，什么都不用改，直接点 Deploy 蓝色大按钮

④ 等待约 30 秒，页面会显示部署进度，出现 🎉 Congratulations! 就说明成功了

⑤ 点击 Visit 按钮，打开你的工作台！

6 获得你的永久公网网址

部署成功后，Vercel 会给你一个网址，格式类似：

你的网址 https://cosmos-workbench-xxx.vercel.app

这个网址是永久有效的，不会休眠，不会过期，全球都能访问。

怎么再找到这个网址？登录 vercel.com → 左侧 Dashboard → 点你的项目名 → 顶部就是网址。
✅ 到这里，第一部分完成！把这个网址发给手机，在小米 15 浏览器打开就能用。继续做第二部分配置数据同步。
☁️ 第二部分

配置 jsonbin.io 双向数据同步

目标：电脑上输入的数据自动同步到手机，手机上输入的数据自动同步到电脑。配置一次，以后全自动。

注册 jsonbin.io → 创建数据仓库 → 复制两串密钥 → 粘贴到工作台
1 注册 jsonbin.io 免费账号

① 在电脑浏览器打开 https://jsonbin.io

② 点击页面右上角 Sign Up 按钮

③ 填写邮箱和密码 → 点 Sign Up

④ 去邮箱点确认链接激活账号

⑤ 登录后页面跳转到控制台首页，看到左侧菜单栏，注册成功

免费额度：每月 10,000 次读写请求。工作台每 5 分钟同步一次，一天约 288 次，一个月约 8,640 次，完全够用。
2 创建一个数据存储仓库（Bin）

① 登录后，在左侧菜单点击 New Bin

② 页面出现一个代码编辑框，里面有一些默认文字，全部删除

③ 在编辑框里输入一个大括号：

输入这串 {}

④ 给这个 Bin 起个名字：在 Bin Name 输入框里填 cosmos-sync（名字随便取，方便记忆）

⑤ 点击 Publish 或 Create 按钮，创建成功

⑥ 创建后页面跳转，你会看到一个网址，类似：

这是你的 Bin URL https://api.jsonbin.io/v3/b/684a3b2face6f34c4fcaf1b3

⑦ 把这一整段网址复制保存好（这是第一个要粘贴到工作台的东西）

重要：这个网址后面那串字母数字混合的就是你的 Bin ID。整个网址要完整复制，包括 https://api.jsonbin.io/v3/b/ 前缀。
3 获取访问密钥（API Key）

① 点击页面左下角你的头像或用户名 → 选择 API Keys

（或者直接打开 https://jsonbin.io/api-keys）

② 页面显示你的 X-Master-Key，是一串以 $2a$10$ 开头的很长很长的字符串，类似：

这是你的密钥 $2a$10$O8sQ3vXyZabcDEFghIJKLmnopQRSTuvwxyz1234567890abcdefghijklmnop

③ 点击旁边的 Copy 按钮复制（或者手动全选复制）

④ 把这段密钥保存好（这是第二个要粘贴到工作台的东西）

注意：密钥很长，一定要完整复制，不能漏字符。建议用旁边的 Copy 按钮而不是手动选。
4 在电脑端工作台填写同步配置

① 在电脑浏览器打开你的 Vercel 工作台网址

② 点击侧边栏底部的 ⚙️ 数据管理 按钮

③ 弹出「数据管理中心」面板，向下滚动找到 ☁️ 跨设备云端同步 区域

④ 你会看到 3 个输入框，按下面的对照填写：

输入框名称填什么
同步空间标识 自己取一个好记的名字，比如 my-office-2026
⚠️ 手机端要填一模一样的名字才能配对同步
云端存储端点 URL 粘贴第 2 步复制的 Bin URL
⚠️ 就是 https://api.jsonbin.io/v3/b/xxxxx 那个
访问密钥 Token 粘贴第 3 步复制的 X-Master-Key
⚠️ 就是 $2a$10$xxx... 那个

⑤ 确认下方 自动实时同步 开关是打开状态（蓝色）

⑥ 点击 💾 保存配置 按钮，弹出提示「同步配置已保存 ✓」

⑦ 点击 🔄 立即同步 按钮，弹出提示「数据同步完成 ✓」

✅ 电脑端配置完成！现在电脑上的数据已经上传到云端了。继续在手机端做相同配置。
5 在小米手机端工作台填写相同的同步配置

① 在小米 15 手机浏览器打开同一个 Vercel 工作台网址

② 点击左上角 ☰ 汉堡菜单按钮 → 展开侧边栏

③ 点击侧边栏底部的 ⚙️ 数据管理

④ 在 ☁️ 跨设备云端同步 区域，填入与电脑端完全相同的 3 个值：

输入框手机端填
同步空间标识必须和电脑一样，比如 my-office-2026
云端存储端点 URL同一个 Bin URL
访问密钥 Token同一个 X-Master-Key

⑤ 点击 💾 保存配置 → 再点 🔄 立即同步

⑥ 弹出提示「同步成功：新增 XX 条」就说明电脑端的数据已经同步到手机了！

✅ 双向同步配置完成！现在你在电脑上打卡、写日记、加单词，手机端自动同步最新内容；反过来也一样。
💡 同步怎么自动运行的？需要我做什么吗？

不用做任何事，全自动！配置好之后：

✅ 你在任意一端修改数据 → 5 秒后自动上传到云端

✅ 打开工作台时 → 自动拉取云端最新数据并合并

✅ 每隔 5 分钟 → 自动同步一次

✅ 手机断网后恢复网络 → 自动同步

✅ 想立刻同步？点侧边栏 ☁️ 同步 按钮一键强制同步

数据安全：所有数据先存在你设备的 IndexedDB 里（浏览器关了也不会丢），再同步到云端。即使 jsonbin.io 挂了，本地数据还在。还可以随时在「数据管理」里导出 JSON 备份。
📱 第三部分

小米手机添加桌面图标（PWA 安装）

目标：在小米 15 桌面生成「宇宙边角办事处」独立图标，点击后全屏启动，像原生 App 一样，没有浏览器地址栏。

打开网址 → 点菜单 → 添加到桌面 → 全屏使用
1 在小米手机浏览器打开工作台网址

① 打开小米 15 自带的浏览器（或 Chrome / Edge 都行）

② 在地址栏输入你的 Vercel 网址：

你的网址 https://cosmos-workbench-xxx.vercel.app

③ 按回车，等待页面加载完成，看到「宇宙边角办事处」工作台界面

重要：网址必须是 https:// 开头（Vercel 自动给你 HTTPS），否则无法安装 PWA。
2 打开浏览器菜单

根据你用的浏览器，找到菜单按钮：

小米浏览器：点击底部正下方的 ☰ 三条线菜单按钮

Chrome：点击右上角 ⋮ 三个点按钮

Edge：点击右下角 ⋯ 三个点按钮

菜单从底部弹出，显示一排图标选项

3 选择「添加到桌面」或「安装应用」

在弹出的菜单中找到并点击：

小米浏览器：找到 添加到桌面 → 点击

Chrome：找到 安装应用 或 添加到主屏幕 → 点击

Edge：找到 添加到手机 → 选 安装

Chrome 额外提示：如果你在地址栏右侧看到一个 📲 安装图标，也可以直接点那个图标，跳过菜单。
4 确认安装，桌面生成图标

① 弹出一个确认窗口，显示「宇宙边角办事处」的图标和名称

② 点击 添加 或 安装 按钮确认

③ 提示「已添加到主屏幕」

④ 回到手机桌面，你会看到一个独立的 「边角办事处」 应用图标

5 点击桌面图标，全屏启动

① 在手机桌面找到「边角办事处」图标，点击它

② 工作台全屏启动，没有浏览器地址栏，没有底部导航栏，就像一个真正的 App

③ 首次打开可能需要联网加载一下（Service Worker 缓存页面）

④ 之后即使断网也能打开使用（离线模式），联网后自动同步数据

✅ 全部搞定！你现在可以像用原生 App 一样使用「宇宙边角办事处」了。
6 安装后配置数据同步（如果还没配）

如果第二部分的同步配置你还没在手机端做，现在补上：

① 打开桌面图标启动工作台

② 点左上角 ☰ → 点 ⚙️ 数据管理

③ 填入与电脑端相同的同步空间标识、Bin URL、X-Master-Key（参照第二部分第 5 步）

④ 点 💾 保存配置 → 点 🔄 立即同步

⑤ 电脑端的数据就同步过来了！

🎯 总结

全部完成后的效果

三部分都做完后，你拥有：

🌐 永久公网网址：https://cosmos-workbench-xxx.vercel.app
电脑、手机、任何设备打开都能用，不会休眠

☁️ 自动数据同步：电脑上打卡写日记 → 手机自动收到
手机上加单词 → 电脑自动同步，完全不用手动操作

📱 手机桌面 App：小米 15 桌面有独立图标，全屏启动
离线也能用，联网自动同步，体验和原生 App 一样

💡 遇到问题？
• 网页打不开 → 检查 Vercel 部署是否成功，网址是否正确
• 同步不生效 → 检查两端填的 3 个值是否完全一致，点「一键强制同步」
• PWA 装不了 → 确保网址是 https:// 开头，换 Chrome 浏览器试试
• 手机端显示旧版 → 下拉刷新页面，或清除浏览器缓存后重新打开
